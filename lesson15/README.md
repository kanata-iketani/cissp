# 第15章 ネットワーク機器・セグメンテーション・ゼロトラスト【D4】

ネットワークを「どう区切り、どこで通信を検査するか」はD4の中心テーマです。この章ではファイアウォールの世代、セグメンテーションの手法、SDNなどの仮想化技術、そして試験でも実務でも主役になりつつあるゼロトラストとNACを学びます。

## 1. ファイアウォールの進化

### ファイアウォールの世代

ファイアウォール (firewall) は「どの層の情報まで見て判断するか」で世代分けできます。この対比は超頻出です。

| 世代 | 見るもの | 特徴 |
|---|---|---|
| パケットフィルタ (static packet filtering) | IPアドレス・ポート番号 (L3/L4) | ルール表で1パケットずつ判断。速いが文脈を見ない |
| ステートフルインスペクション (stateful inspection) | 接続状態テーブル | 「確立済み通信の応答か」を判断できる。現在の標準 |
| アプリケーションレベル (proxy firewall) | アプリ層の中身 (L7) | 通信を代理終端して検査。精密だが遅い |
| 次世代FW (NGFW) | DPI・アプリ識別・ユーザー識別 | IPS・URLフィルタ等を統合した多機能型 |

Web アプリ専用に SQL インジェクションや XSS を検査するのが **WAF (Web Application Firewall)** です。

### 設計の基本

- ルールの最後は**デフォルト拒否 (implicit deny)**。明示的に許可した通信以外はすべて拒否します
- 公開サーバー(Web・メール・DNS)は内部LANに置かず、外部FWと内部FWで挟んだ**スクリーンドサブネット (screened subnet、いわゆるDMZ)** に置きます
- 内→外の通信を絞る**エグレスフィルタリング (egress filtering)** は、マルウェアの C2 通信や情報持ち出しの発見に有効です

💡 コツ: 試験で「侵害された公開サーバーから内部への被害を最小化する構成は?」と来たらスクリーンドサブネット、「社内からの不審な外向き通信を見つけたい」と来たらエグレスフィルタリングが正解筋です。

### 確認問題

**問1.** ステートフルインスペクション型ファイアウォールが静的パケットフィルタより優れている点として、最も適切なものはどれですか。

1. アプリケーション層のペイロードを完全に復号して検査できる
2. 通信を代理終端するため内部ネットワークを完全に隠蔽できる
3. 接続状態テーブルを保持し、確立済みセッションの応答かどうかを文脈で判断できる
4. ルールを設定しなくても自動的に不正通信を学習して遮断できる

<details><summary>答えと解説</summary>

正解: **3**

ステートフルインスペクションは接続状態 (state) を記録し、「この戻りパケットは内部から始まった正当なセッションの応答か」を判断できます。これが静的フィルタとの決定的な違いです。アプリ層の中身まで見るのはプロキシ型や NGFW の DPI、代理終端はプロキシ型の特徴で、自動学習はファイアウォール一般の機能ではありません。試験では「どの世代が何を見るか」を入れ替えて出すひっかけが定番です。

</details>

**問2.** インターネットに公開する Web サーバーを設置する場所として、最も適切 (BEST) なのはどれですか。

1. 外部ファイアウォールと内部ファイアウォールに挟まれたスクリーンドサブネット
2. 利便性を考慮した社内 LAN の内部セグメント
3. ファイアウォールを介さずインターネットに直結した境界の外側
4. 経営層専用ネットワークと同一のセグメント

<details><summary>答えと解説</summary>

正解: **1**

公開サーバーは侵害される前提で、外部からはアクセスさせつつ内部 LAN からは分離するスクリーンドサブネット (DMZ) に置くのが定石です。社内 LAN に置くと侵害時に内部へ横展開され、境界の外に直結すると保護が一切なく、経営層ネットワークとの同居は論外です。「公開サーバー=DMZ」は反射で答えられるようにしましょう。

</details>

**問3.** 次世代ファイアウォール (NGFW) を従来型と区別する特徴として、最も適切なものはどれですか。

1. IP アドレスとポート番号のみで高速に通信を制御する
2. ディープパケットインスペクションによるアプリケーション識別と IPS 等の統合機能を持つ
3. 磁気媒体を消磁してデータ残留を防止する
4. 接続状態を一切保持しないことで単純性を高めている

<details><summary>答えと解説</summary>

正解: **2**

NGFW はポート番号に頼らず DPI (deep packet inspection) で「どのアプリの通信か」を識別し、IPS・URL フィルタ・ユーザー識別などを1台に統合します。IP とポートのみの制御はパケットフィルタの説明、消磁はデータ廃棄の話でネットワークと無関係、状態を保持しないのはむしろ旧世代の特徴です。「ポート 443 だから安全とは言えない」場面で NGFW のアプリ識別が活きます。

</details>

**問4.** ファイアウォールのルール設計における「デフォルト拒否 (implicit deny)」の意味として正しいものはどれですか。

1. 管理者の通信だけは常に無条件で許可する
2. 営業時間外はすべての通信を拒否する
3. 拒否ルールに一致した通信のみを拒否し、それ以外は許可する
4. 明示的に許可されていない通信は、最終的にすべて拒否する

<details><summary>答えと解説</summary>

正解: **4**

デフォルト拒否は「許可リストに載っていないものはすべて拒否」という設計原則で、最小権限の考え方をネットワークに適用したものです。「拒否ルールに一致した通信のみを拒否し…」はその逆のデフォルト許可 (default allow) で危険な設計です。管理者の無条件許可は特権の濫用リスクがあり、時間帯による拒否は単なるルールの一種にすぎません。「allow list が基本、deny list は漏れる」という感覚を持ちましょう。

</details>

**問5.** マルウェア感染端末から外部の C2 サーバーへの通信を発見・遮断する目的で導入する対策として、最も適切 (MOST) なのはどれですか。

1. 外部から内部へのインバウンド通信の全面許可
2. ネイティブ VLAN の変更
3. 内部から外部への通信を必要最小限に絞るエグレスフィルタリング
4. スイッチのポートミラーリングの無効化

<details><summary>答えと解説</summary>

正解: **3**

エグレスフィルタリング (egress filtering) は内→外の通信を検査・制限する対策で、C2 通信やデータ持ち出しの発見に直結します。多くの組織は外→内ばかり守り、内→外が素通しになりがちです。インバウンド全面許可は論外、ネイティブ VLAN 変更は VLAN ホッピング対策、ポートミラーリング無効化はむしろ監視能力を下げます。「出ていく通信も疑う」のが CISSP 的視点です。

</details>

## 2. ネットワークセグメンテーション

### なぜ区切るのか

セグメンテーション (segmentation) の目的は3つです。①侵害時の**影響範囲の限定**(横展開の防止)、②ブロードキャストを減らす**性能向上**、③カード情報環境の分離など**コンプライアンス対応**(監査範囲の縮小)。

### 代表的な手法

| 手法 | 分離のレベル |
|---|---|
| サブネット分割 | L3。ルータ/FW で通信を制御 |
| VLAN | L2。スイッチ上で**ブロードキャストドメインを論理分割** |
| マイクロセグメンテーション (microsegmentation) | ワークロード単位。データセンター内の東西 (east-west) トラフィックも個別に制御 |
| エアギャップ (air gap) | 物理的に接続しない**最強の分離**。ただし運用コスト大 |

- **イントラネット**は内部専用、**エクストラネット**は取引先など限定された外部に開放する中間領域です
- 機器の管理用通信は本番トラフィックと分けた**帯域外管理 (out-of-band management)** が推奨です

### VLAN ホッピング対策

攻撃者がタグを偽装して別 VLAN に侵入する VLAN ホッピングには、未使用ポートの無効化、ポートのトランク自動ネゴシエーション無効化、**ネイティブ VLAN をデフォルト (VLAN 1) から変更**するなどで対抗します。

💡 コツ: 「監査範囲 (スコープ) を減らしたい」「感染の横展開を止めたい」と来たらセグメンテーション。「絶対に外部と接続してはならないシステム」と来たらエアギャップが正解筋です。

### 確認問題

**問1.** VLAN によるネットワーク分割の説明として、最も適切なものはどれですか。

1. 物理的な配線を完全に分離し、電気的に独立したネットワークを作る
2. スイッチ上でブロードキャストドメインを論理的に分割する
3. 暗号化によってデータの機密性を保証する
4. インターネットとの境界にのみ適用できる技術である

<details><summary>答えと解説</summary>

正解: **2**

VLAN は1台(または複数)のスイッチ上に論理的なネットワークを複数作り、ブロードキャストドメインを分割する L2 の技術です。物理的な分離はエアギャップの説明で、VLAN はあくまで論理分割です。暗号化の機能はなく、内部ネットワークのどこでも使えます。「VLAN =論理、エアギャップ=物理」の対比はひっかけの定番です。

</details>

**問2.** 産業制御システムを外部ネットワークから最も強力に分離する方法はどれですか。

1. NGFW によるアプリケーション制御
2. VLAN による論理分割
3. プロキシサーバー経由の通信
4. エアギャップによる物理的分離

<details><summary>答えと解説</summary>

正解: **4**

エアギャップ (air gap) はネットワークを物理的に接続しないため、ネットワーク経由の攻撃を原理的に遮断する最強の分離です。NGFW・VLAN・プロキシはいずれも接続を前提とした制御であり、設定ミスや脆弱性で突破される可能性が残ります。ただしエアギャップも USB メモリ等の媒体経由では侵害され得る点、パッチ適用などの運用コストが大きい点は押さえておきましょう。

</details>

**問3.** クレジットカード情報を扱うサーバー群について、コンプライアンス監査の対象範囲を縮小しつつ侵害時の横展開を防ぎたいと考えています。最も適切 (BEST) な対策はどれですか。

1. 全社ネットワークを単一のフラットな構成に統合する
2. カード情報環境を専用セグメントに分離し、他セグメントとの通信をファイアウォールで制限する
3. カード情報環境のサーバーにのみウイルス対策ソフトを導入する
4. 全従業員にカード情報環境へのアクセス権を付与して管理を一元化する

<details><summary>答えと解説</summary>

正解: **2**

セグメンテーションでカード情報環境 (CDE) を分離すれば、監査のスコープがそのセグメントに限定され、侵害時の横展開も防げます。フラットな構成は真逆で全体が監査対象かつ横展開し放題になります。ウイルス対策だけでは範囲縮小にならず、全員へのアクセス権付与は最小権限違反です。「スコープ縮小」というキーワードからセグメンテーションを連想できるようにしましょう。

</details>

**問4.** VLAN ホッピング攻撃への対策として適切でないものはどれですか。

1. 未使用のスイッチポートを無効化する
2. ポートのトランク自動ネゴシエーションを無効化する
3. すべてのポートをデフォルトのネイティブ VLAN 1 のまま運用する
4. ネイティブ VLAN をデフォルトから別の VLAN に変更する

<details><summary>答えと解説</summary>

正解: **3**

VLAN ホッピングは二重タグ付けやトランクポートへの偽装接続で別 VLAN に侵入する攻撃です。対策は未使用ポートの無効化、トランク自動ネゴシエーションの無効化、ネイティブ VLAN のデフォルト (VLAN 1) からの変更です。「VLAN 1 のまま運用」は攻撃を容易にする設定であり、対策として不適切です。『適切でないもの』を選ぶ否定形の設問は読み飛ばしやすいので要注意です。

</details>

**問5.** マイクロセグメンテーションの説明として、最も適切なものはどれですか。

1. データセンター内のワークロード単位で通信ポリシーを適用し、東西トラフィックも制御する
2. 建物のフロアごとに物理スイッチを分けて設置する
3. インターネット境界の南北トラフィックだけを集中管理する
4. 無線 LAN の SSID を部署ごとに分ける

<details><summary>答えと解説</summary>

正解: **1**

マイクロセグメンテーションは VM・コンテナなどワークロード単位の細かい粒度でポリシーを適用し、従来の境界型防御では素通しだったデータセンター内部の東西 (east-west) トラフィックまで制御します。ゼロトラストの実装手段の一つです。フロア単位の物理分割や SSID 分割は粗い粒度の分離で、境界の南北トラフィックのみの管理はむしろ従来型の発想です。

</details>

## 3. SDN・SD-WAN・仮想ネットワーク

### SDN — ネットワークをソフトウェアで定義する

**SDN (Software-Defined Networking)** の本質は、経路判断を行う**コントロールプレーン**と、実際にパケットを転送する**データプレーン**の分離です。判断機能を集中させた **SDN コントローラ**がネットワーク全体を一元管理します。

| API | つなぐもの | 例 |
|---|---|---|
| サウスバウンド API | コントローラ ⇔ ネットワーク機器 | OpenFlow |
| ノースバウンド API | コントローラ ⇔ 管理アプリ | REST API |

セキュリティ上の要点: コントローラは**単一障害点であり最重要の攻撃対象**です。乗っ取られればネットワーク全体を支配されるため、アクセス制御・冗長化・通信の暗号化が必須です。

### 関連技術

- **SD-WAN**: MPLS 専用線とインターネット回線など複数の WAN 回線を、アプリ要件に応じてポリシーで使い分ける仮想 WAN
- **NFV (Network Functions Virtualization)**: FW やルータなどの機能を専用アプライアンスから仮想マシンへ
- **VXLAN**: L2 ネットワークを L3 上に延伸するカプセル化。VLAN の 4094 個制限を超えられます
- クラウドでは **VPC** で仮想ネットワークを作り、インスタンス単位の仮想 FW である**セキュリティグループ**で通信を制御します

💡 コツ: SDN の問題は「何と何を分離するか」と「何を最優先で守るか(=コントローラ)」の2点がほぼすべてです。

### 確認問題

**問1.** SDN (Software-Defined Networking) の本質的な特徴として、最も適切なものはどれですか。

1. すべてのネットワーク機器を物理的に冗長化すること
2. ネットワーク通信を全区間で暗号化すること
3. 無線 LAN と有線 LAN を統合すること
4. コントロールプレーンとデータプレーンを分離し、制御を集中させること

<details><summary>答えと解説</summary>

正解: **4**

SDN は経路判断(コントロールプレーン)をパケット転送(データプレーン)から切り離し、コントローラに集中させるアーキテクチャです。これにより設定の一元化・自動化が可能になります。物理冗長化・暗号化・無線統合はいずれも SDN の定義ではありません。試験では「何と何の分離か」を問う素直な出題が多いので、この一点を確実に覚えましょう。

</details>

**問2.** SDN 環境においてセキュリティ上最も優先して保護すべき (MOST) 要素はどれですか。

1. 各フロアのアクセススイッチ
2. SDN コントローラ
3. 利用者の端末
4. パッチパネルの配線

<details><summary>答えと解説</summary>

正解: **2**

SDN コントローラはネットワーク全体の制御を握る頭脳であり、単一障害点かつ最大の攻撃対象です。侵害されればすべての経路制御を攻撃者に支配されます。アクセススイッチや端末の保護も必要ですが、影響範囲の大きさが桁違いです。「集中管理は効率と引き換えに、集中点が最重要資産になる」という CISSP 的なトレードオフの考え方が問われています。

</details>

**問3.** SDN におけるサウスバウンド API の役割として正しいものはどれですか。

1. コントローラとスイッチ等のネットワーク機器の間の通信
2. 管理アプリケーションとコントローラの間の通信
3. 拠点間の WAN 回線同士の通信
4. 利用者端末と認証サーバーの間の通信

<details><summary>答えと解説</summary>

正解: **1**

サウスバウンド API はコントローラから見て「南(下)」、つまり配下のネットワーク機器との通信で、OpenFlow が代表例です。管理アプリとの通信は「北(上)」のノースバウンド API です。地図で上が北というイメージで、アプリ=上位・機器=下位と覚えると混同しません。残り2つは SDN の API とは無関係です。

</details>

**問4.** 複数拠点を持つ企業が、MPLS 専用線とインターネット VPN を併用し、アプリケーションの要件に応じて回線を自動で使い分けたいと考えています。最も適切な技術はどれですか。

1. VLAN トランキング
2. ポートミラーリング
3. SD-WAN
4. NAT

<details><summary>答えと解説</summary>

正解: **3**

SD-WAN は複数の WAN 回線を抽象化し、「基幹系は専用線、Web 会議はインターネット直抜け」のようにポリシーベースで経路を使い分ける技術です。高価な MPLS への依存を減らしつつ品質を保てます。VLAN トランキングは LAN 内の技術、ポートミラーリングは監視用のコピー、NAT はアドレス変換であり、WAN 回線の使い分けはできません。

</details>

**問5.** クラウド環境の「セキュリティグループ」の説明として、最も適切なものはどれですか。

1. クラウド事業者の社内セキュリティ組織の名称
2. データセンターの入退室を管理する物理的な仕組み
3. 複数のクラウドアカウントを束ねる課金単位
4. インスタンス単位で通信を制御する仮想ファイアウォール機能

<details><summary>答えと解説</summary>

正解: **4**

セキュリティグループは VPC 内のインスタンス(仮想マシン)単位に適用する仮想ファイアウォールで、許可ルールを記述して通信を制御します。物理の境界 FW が1か所で守るのに対し、ワークロードごとに制御できる点がマイクロセグメンテーション的です。組織名・入退室管理・課金単位はいずれも誤りで、名前の印象に引きずられないよう注意しましょう。

</details>

## 4. ゼロトラストとNAC

### ゼロトラスト — 「社内だから安全」をやめる

従来の境界型防御は「外は危険、中は安全」という前提でした。**ゼロトラスト (zero trust)** はこれを捨て、「**決して信頼せず、常に検証する (never trust, always verify)**」を原則とします。NIST SP 800-207 では、アクセスのたびにユーザー・デバイス・文脈を評価して**資産単位で最小権限のアクセス**を許可します。許可を判断する**ポリシー決定点 (PDP)** と、通信を実際に通す/止める**ポリシー実施点 (PEP)** という概念で整理されます。

**SASE (Secure Access Service Edge)** は、SD-WAN に SWG・CASB・ZTNA などのセキュリティ機能を加えてクラウドサービスとして提供するモデルで、場所を問わない働き方とゼロトラストを支えます。

### NAC と 802.1X

**NAC (Network Access Control)** は、端末がネットワークに接続する時点で認証と**ポスチャ評価**(パッチ・ウイルス対策の状態確認)を行い、基準を満たさない端末を**検疫 (quarantine) ネットワーク**に隔離します。

認証の標準が **IEEE 802.1X** で、3つの登場人物を押さえましょう(超頻出)。

| 役割 | 実体 |
|---|---|
| サプリカント (supplicant) | 接続したい端末側のソフト |
| オーセンティケータ (authenticator) | スイッチや無線 AP |
| 認証サーバー (authentication server) | RADIUS サーバー |

💡 コツ: MAC アドレスフィルタリングは MAC が容易に偽装できるため**単独では不十分**です。「手軽な対策 vs 本物の認証 (802.1X)」の対比で出題されます。

### 確認問題

**問1.** ゼロトラストアーキテクチャの基本原則として、最も適切なものはどれですか。

1. 社内ネットワークからのアクセスは信頼し、社外からのアクセスのみ検証する
2. ネットワーク上の位置にかかわらず、アクセス要求のたびに検証して最小権限で許可する
3. 一度認証に成功した端末は、以後すべてのリソースへ自由にアクセスできるようにする
4. 境界ファイアウォールを強化すれば内部の制御は不要になる

<details><summary>答えと解説</summary>

正解: **2**

ゼロトラストは「社内=安全」という暗黙の信頼を排除し、場所を問わずアクセスごとにユーザー・デバイス・文脈を検証して資産単位の最小権限を適用します。社内を無条件に信頼する、一度の認証で全リソース開放、境界だけ強化という選択肢はすべて従来の境界型防御の発想で、ゼロトラストの対極です。「never trust, always verify」を言い換えた選択肢を選べるようにしましょう。

</details>

**問2.** IEEE 802.1X においてオーセンティケータの役割を担う機器はどれですか。

1. 接続を要求する利用者の端末
2. 認証情報を検証する RADIUS サーバー
3. ディレクトリ情報を保管する LDAP サーバー
4. 端末が接続するスイッチや無線アクセスポイント

<details><summary>答えと解説</summary>

正解: **4**

802.1X の3要素は、端末側のサプリカント、中継役のオーセンティケータ(スイッチ・無線 AP)、検証役の認証サーバー(RADIUS)です。オーセンティケータは自分では認証を判断せず、サプリカントと認証サーバーの間を取り次いでポートの開閉だけを行います。「オーセンティケータ=認証サーバー」と誤解させるのが定番のひっかけなので、名前に惑わされないようにしましょう。

</details>

**問3.** NAC のポスチャ評価で OS パッチが未適用と判定された端末の扱いとして、最も適切 (BEST) なのはどれですか。

1. 検疫ネットワークに隔離し、修復後に本番ネットワークへの接続を許可する
2. 業務影響を避けるため、そのまま本番ネットワークへの接続を許可する
3. 端末を即座に初期化して全データを消去する
4. 利用者のアカウントを恒久的に削除する

<details><summary>答えと解説</summary>

正解: **1**

NAC の標準的な動作は、基準を満たさない端末を検疫 (quarantine) ネットワークへ隔離し、パッチ適用などの修復 (remediation) を行ってから本番への接続を許可する流れです。そのまま接続させては NAC の意味がなく、即初期化やアカウント恒久削除は業務影響に対して過剰です。「隔離→修復→再評価」という、セキュリティと業務継続のバランスを取る選択肢が CISSP の正解筋です。

</details>

**問4.** SASE (Secure Access Service Edge) の説明として、最も適切なものはどれですか。

1. データセンター内の物理サーバーを集約する仮想化基盤
2. SD-WAN と SWG・CASB・ZTNA 等のセキュリティ機能をクラウドサービスとして統合提供するモデル
3. 建物の入退室管理と監視カメラを統合した物理セキュリティ製品
4. バックアップデータを遠隔地に複製する災害対策サービス

<details><summary>答えと解説</summary>

正解: **2**

SASE はネットワーク機能 (SD-WAN) とセキュリティ機能 (セキュア Web ゲートウェイ、CASB、ゼロトラストネットワークアクセスなど) をクラウドのエッジで統合提供するモデルです。利用者がどこにいても同じポリシーを適用でき、ゼロトラストの実現手段として出題が増えています。仮想化基盤・物理セキュリティ・バックアップはいずれも無関係です。

</details>

**問5.** 無線 LAN のアクセス制御として MAC アドレスフィルタリングのみを使うことの問題点として、最も適切なものはどれですか。

1. MAC アドレスは暗号化されるため管理者が登録作業をできない
2. MAC アドレスフィルタリングを使うと通信速度が半分になる
3. MAC アドレスは容易に偽装できるため、単独では実質的な認証にならない
4. MAC アドレスフィルタリングは法律で使用が禁止されている

<details><summary>答えと解説</summary>

正解: **3**

MAC アドレスは電波上で平文のまま見えるため、攻撃者は正規端末の MAC を観測して自端末に設定(スプーフィング)できます。したがって MAC フィルタは手軽ですが実質的な認証にはならず、802.1X のような本物の認証と併用すべきです。MAC が暗号化される、速度が半減する、法律で禁止という事実はありません。「手軽な対策の限界」を問う典型問題です。

</details>
