# CISSPどうじょう 🛡️

ISC2 の **CISSP (Certified Information Systems Security Professional)** 認定試験に日本語 CAT 試験で合格することを目指すブラウザ学習アプリです。左に教科書、右に一問一答（4択）。答えるとその場で判定と解説が出ます。

**このアプリは「8ドメイン全部のインプットと理解確認、そして CISSP 特有の『マネジメント視点で BEST を選ぶ』思考の訓練」を担当します。** 仕上げに公式問題集などの演習を足すと盤石です（勉強戦略は第1章で解説）。

## 試験の概要（2024年4月15日改定アウトライン準拠）

- 形式: **CAT（コンピュータ適応型）**・全言語対応。**3時間・100〜150問**・見直し不可
- 合格基準: スケールスコア **700 / 1000**
- 8ドメインと出題比率: D1 セキュリティとリスクマネジメント 16% / D2 資産のセキュリティ 10% / D3 セキュリティアーキテクチャとエンジニアリング 13% / D4 通信とネットワークのセキュリティ 13% / D5 アイデンティティとアクセスの管理 13% / D6 セキュリティの評価とテスト 12% / D7 セキュリティの運用 13% / D8 ソフトウェア開発セキュリティ 10%

## 使い方

```sh
cd cissp
go -C app run .
```

ブラウザで <http://127.0.0.1:8086> を開いてください。必要なのは [Go](https://go.dev/dl/) 1.22+ だけです。

## 構成（全34章）

| パート | 章 | 対応ドメイン |
|---|---|---|
| 試験戦略（CAT・マネジメント視点・日本語受験） | 第1章 | 全体 |
| セキュリティとリスクマネジメント | 第2〜6章 | **D1 (16%)** |
| 資産のセキュリティ | 第7〜8章 | **D2 (10%)** |
| セキュリティアーキテクチャとエンジニアリング | 第9〜13章 | **D3 (13%)** |
| 通信とネットワークのセキュリティ | 第14〜17章 | **D4 (13%)** |
| アイデンティティとアクセスの管理 (IAM) | 第18〜20章 | **D5 (13%)** |
| セキュリティの評価とテスト | 第21〜22章 | **D6 (12%)** |
| セキュリティの運用 | 第23〜27章 | **D7 (13%)** |
| ソフトウェア開発セキュリティ | 第28〜30章 | **D8 (10%)** |
| シナリオドリル（BEST/MOST 問題） | 第31〜32章 | 全ドメイン横断 |
| 本試験形式の模試（各50問・出題比率準拠） | 第33〜34章 | 全ドメイン |

- 全問正解でチャプタークリア ✅。間違えた問題は **にがて帳** に自動記録され、ワンクリックで解き直せます
- CISSP は「技術的に正しい」より「管理者としてどれが BEST か」を問う試験です。🎤 **口頭試問** で「なぜそれが BEST か」を自分の言葉で説明する練習が特に効きます

## AI の先生（ローカルに [Claude Code](https://claude.com/claude-code) がある場合）

「🙋 質問」からいつでも使えます。なくても学習機能はすべて使えます。

| 機能 | 何をしてくれるか |
|---|---|
| 💬 質問 | いま学んでいるチャプターの文脈で、英語の原語つきでかみ砕いて回答 |
| 🎤 口頭試問 | 「なぜそれが BEST か」を記述させて採点。CISSP 的思考を鍛える |
| 📝 弱点まとめ | 全誤答・全質問を分析し、「苦手ドメイントップ3・次にやること」をノート化 |
| 🎯 専用復習問題 | 誤答の多い分野を自動特定し、同じ論点の別角度類題で専用章を生成 |
| 📰 最新動向ノート | AI が Web 検索で試験仕様・出題傾向・新トピックを調べて出典付きノートを作成 |

AI の利用量はリポジトリ直下の `ai-config.json` で管理できます（GitHub 上で編集すると起動中のアプリに約10分で自動反映。`-1`=無制限 / `0`=停止 / 正の数=1日の上限）。

## 教材データ

正データは `lessonNN/chMM.json`（教科書 `text` + 4択 `quiz`）。編集後は `go run ./tools/coursegen` で検証します。

本教材の問題はすべてオリジナルです（実際の試験問題・公式問題集の転載ではありません）。
