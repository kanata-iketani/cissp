# 第1章 CISSP試験のきほんと合格戦略（CAT・マネジメント視点）

CISSP がどんな試験か、どう攻略するかを最初に固める章です。受験要件・CAT 方式のルール・そして最重要の「マネジメント視点 (Think like a Manager)」という解法の軸を身につけてから、第2章以降のドメイン学習に進みましょう。

## 1. CISSP試験とは — 資格の価値と受験要件

### CISSP はどんな資格か

CISSP (Certified Information Systems Security Professional) は、国際的な非営利団体 **ISC2** が認定するセキュリティ資格です。世界中で通用するセキュリティ資格の代表格で、特徴は「手を動かす技術者」ではなく**セキュリティを組織として管理する立場（マネジメント寄り）**の知識を問うことです。ファイアウォールの設定コマンドではなく、「組織として何を優先し、どう意思決定するか」が問われます。

### 受験要件と認定までの流れ

CISSP の出題範囲は **8つのドメイン**（出題分野のこと。D1 リスクマネジメント〜D8 ソフトウェア開発。一覧は次の章）に分かれています。実務経験もこのドメイン単位で数えます。

| 項目 | 内容 |
|---|---|
| 実務経験 | 8ドメインのうち **2ドメイン以上**で**累計5年** |
| 経験の免除 | 大学の学位や認定資格で **1年分**免除（最大1年） |
| 経験が足りない場合 | 試験合格で **Associate of ISC2** になり、後から経験を満たす（猶予は合格から6年） |
| 合格後 | 有資格者による**推薦 (endorsement)**（申告した経歴が本物だと有資格者が保証する手続き）を受けて正式認定 |
| 維持 | **CPE**（継続教育の単位。研修やセミナー受講1時間でおおむね1単位）を**3年間で120単位**＋年会費（AMF: Annual Maintenance Fee）の支払い |

#### 経験年数の数え方（例）

| 人 | 実務経験 | 学位など | 判定 |
|---|---|---|---|
| Aさん | ネットワーク運用 (D4) 3年＋ID管理 (D5) 2年 | なし | 2ドメイン・累計5年 → 要件を満たす |
| Bさん | セキュリティ運用 (D7) 2年＋脆弱性診断 (D6) 2年 | 情報系の学位あり | 累計4年＋免除1年＝5年 → 要件を満たす |
| Cさん | セキュリティ運用 (D7) 1年 | なし | 不足 → 合格すると Associate of ISC2。6年以内に残りの経験を積めば認定 |

受験は **Pearson VUE**（世界各地で試験会場を運営する会社）のテストセンターで行い、受験料は **749米ドル**です。試験は**日本語で受験できます**（英語・中国語・ドイツ語・スペイン語にも対応）。

### 「合格して終わり」ではない

CISSP は合格後も endorsement・CPE・年会費と続く「メンバーシップ型」の資格です。試験勉強の段階から「セキュリティ専門家としての判断基準を身につける」つもりで学ぶと、本試験のマネジメント視点の問題にも強くなります。

💡 コツ: 受験要件の数字（2ドメイン・5年・免除1年・CPE120単位/3年）はそのまま問われ得る基本情報です。最初に覚えてしまいましょう。

### 確認問題

**問1.** CISSP の受験（認定）に必要な実務経験の要件として、正しいものはどれでしょう？

1. 8ドメインすべてで合計10年の実務経験
2. いずれか1ドメインで3年の実務経験
3. 2ドメイン以上で累計5年の実務経験
4. 実務経験は一切不要

<details><summary>答えと解説</summary>

正解: **3**

CISSP の認定要件は「8ドメインのうち2ドメイン以上で累計5年の実務経験」です。学位や認定資格があれば1年分が免除され、実質4年になります。全ドメインの経験は不要で、10年や「1ドメインで3年」という要件もありません。「実務経験ゼロでも試験自体は受けられる（合格すると Associate of ISC2 になれる）」ため、『受験に経験不要＝認定にも不要』と混同させるのが典型的なひっかけです。

</details>

**問2.** 実務経験が足りない人が CISSP 試験に合格した場合、どうなるでしょう？

1. Associate of ISC2 となり、後から経験を満たせば正式認定される
2. 合格は無効になり、再受験が必要になる
3. 即座に CISSP として正式認定される
4. 実務経験の代わりに追加試験を受ける必要がある

<details><summary>答えと解説</summary>

正解: **1**

経験不足で合格した場合は Associate of ISC2 という準会員資格が与えられ、所定の期間内に実務経験を満たせば CISSP として認定されます。合格が無効になることはなく、追加試験もありません。「経験がないと受験すらできない」と誤解されがちですが、試験は受けられる点を押さえましょう。

</details>

**問3.** CISSP 試験合格後、正式認定までに必要な手続きはどれでしょう？

1. ISC2 本部での面接試験
2. 有資格者による推薦 (endorsement)
3. 実技試験（ラボ試験）の合格
4. 勤務先からの英文推薦状の公証

<details><summary>答えと解説</summary>

正解: **2**

合格後は、実務経験を証明するために ISC2 有資格者による推薦 (endorsement) を受けて正式認定されます。身近に有資格者がいない場合は ISC2 自体が推薦者の役割を担う手続きもあります。面接試験やラボ試験は CISSP には存在しません。合格＝即認定ではない点が試験でも問われやすいポイントです。

</details>

**問4.** CISSP の資格維持要件として正しいものはどれでしょう？

1. 毎年再試験を受ける
2. 5年ごとに全ドメインの実務報告書を提出する
3. 維持要件はなく、一度合格すれば生涯有効
4. 3年間で120単位の CPE を取得し、年会費を支払う

<details><summary>答えと解説</summary>

正解: **4**

CISSP は3年のサイクルで CPE (Continuing Professional Education) を120単位取得し、年会費 (AMF) を支払うことで維持します。再試験は不要で、生涯有効でもありません。「CPE は年間120単位」とするひっかけに注意してください（正しくは3年で120単位、年間目安40単位）。

</details>

**問5.** CISSP が他の多くの技術系資格と比べて特徴的なのはどんな点でしょう？

1. 特定ベンダー製品の設定技術を深く問う点
2. プログラミングの実装力を問う点
3. 組織のセキュリティを管理する立場（マネジメント視点）の判断を問う点
4. 物理的な配線やハードウェア修理の技能を問う点

<details><summary>答えと解説</summary>

正解: **3**

CISSP はベンダー中立で、技術の詳細設定よりも「組織としてセキュリティをどう統治・管理するか」というマネジメント視点を問う試験です。特定製品の設定、プログラミング実装、ハードウェア技能が主役になることはありません。この「マネジメント視点」は本講座全体を貫く最重要キーワードで、第3チャプターで詳しく扱います。

</details>

**問6.** 情報系の学位を持つ人が、セキュリティ運用 (D7) の実務を2年、ID管理 (D5) の実務を2年経験しています。CISSP の経験要件の判定として正しいものはどれでしょう？

1. 学位は経験の免除に使えないため、あと1年不足している
2. 1つのドメインで5年の経験が必要なので、要件を満たさない
3. 学位があれば実務経験は一切不要なので、要件を満たす
4. 2ドメインで累計4年、学位による免除1年を足して5年となり、要件を満たす

<details><summary>答えと解説</summary>

正解: **4**

要件は「2ドメイン以上で累計5年」で、学位や認定資格があれば最大1年が免除されます。D7 と D5 の2ドメインで累計4年、免除1年を足して5年になるので要件を満たします。「学位は免除に使えない」は免除制度を知らないと選んでしまう誤りです。「1つのドメインで5年」は要件の数え方を取り違えています。「学位があれば実務経験は一切不要」は免除の上限（1年）を無視した誤りです。

</details>

## 2. CAT方式の攻略法

### CAT（コンピュータ適応型テスト）とは

CISSP 試験は全言語で **CAT (Computerized Adaptive Testing)** 方式です（2024年4月15日改定の試験アウトラインに準拠）。CAT では、正解すると次はより難しい問題、間違えるとやや易しい問題が出題され、コンピュータが受験者の実力を推定していきます。たとえば次のように進みます（難易度は説明用の目安です）。

| 順番 | 出題の難易度 | 回答 | 次の問題 |
|---|---|---|---|
| 1問目 | 中 | 正解 | もう少し難しく |
| 2問目 | やや難 | 正解 | さらに難しく |
| 3問目 | 難 | 不正解 | 少し易しく |
| 4問目 | やや難 | 正解 | … |

こうして「どの難しさの問題までなら正解できるか」を絞り込み、合格ラインより上か下かを十分な確度で判定できた時点で試験が終わります。だから **100問で終わる人もいれば150問まで続く人もいます**。何問で終わったかだけでは合否は分かりません。

| 項目 | 内容 |
|---|---|
| 試験時間 | **3時間** |
| 問題数 | **100〜150問**（採点されないプレテスト問題（将来の出題に向けた試行問題）25問を含む。どれがプレテストかは見分けられない） |
| 合格基準 | スケールスコア **700 / 1000**（正答数をそのまま数えた点ではなく、解いた問題の難しさを加味して 0〜1000 に換算した点） |
| 見直し | **不可**（前の問題に戻れない） |
| 終了条件 | 合否を十分な確度で判定できた時点で早期終了あり |

### 8ドメインの出題比率

| ドメイン | 比率 | ざっくり何を学ぶか | 本講座 |
|---|---|---|---|
| D1 セキュリティとリスクマネジメント | **16%** | ガバナンス・法律・リスク評価・事業継続 | L2〜L6 |
| D2 資産のセキュリティ | 10% | データの分類・保管・廃棄 | L7〜L8 |
| D3 セキュリティアーキテクチャとエンジニアリング | 13% | 安全な設計・暗号・物理対策 | L9〜L13 |
| D4 通信とネットワークのセキュリティ | 13% | ネットワークの仕組みと防御 | L14〜L17 |
| D5 アイデンティティとアクセスの管理 (IAM) | 13% | 本人確認（認証）と権限の管理 | L18〜L20 |
| D6 セキュリティの評価とテスト | 12% | 脆弱性診断・監査 | L21〜L22 |
| D7 セキュリティの運用 | 13% | 監視・インシデント対応・災害復旧 | L23〜L27 |
| D8 ソフトウェア開発セキュリティ | 10% | 安全なソフトウェアの作り方 | L28〜L30 |

### CAT での戦い方

- **1問約1分**のペースを守ります。計算は 180分÷最大150問＝1問あたり1.2分。少し余裕を残すため1分を目安にし、1問に3分以上かけない
- 前に戻れないので「後で見直す」作戦は使えません。**その場で決めて前進**します
- わからない問題も**必ず回答**します。空欄で進むことはできず、悩み続けるほど後半の時間がなくなります
- 難しい問題が続いても動揺しないこと。CAT では**実力が高い人ほど難問が出続ける**のが正常な動作です

💡 コツ: 「最低100問・最大150問・3時間・700点・戻れない」をワンセットで暗記しましょう。模試（第33〜34章）では1問1分ペースの体感も練習します。

### 確認問題

**問1.** CISSP の CAT 方式試験の問題数と試験時間の組み合わせとして正しいものはどれでしょう？

1. 100〜150問・3時間
2. 250問・6時間
3. 125〜175問・4時間
4. 80問・2時間

<details><summary>答えと解説</summary>

正解: **1**

現行の CISSP 試験（2024年4月15日改定アウトライン準拠）は CAT 方式で 100〜150問・3時間です。250問・6時間は CAT 導入前の旧線形方式の数字で、古い情報としてひっかけに使われやすいので注意しましょう。

</details>

**問2.** CISSP 試験の合格基準として正しいものはどれでしょう？

1. 全問題の60%以上の正答率
2. 1000点満点中800点以上
3. スケールスコアで1000点満点中700点以上
4. 受験者全体の上位30%に入ること

<details><summary>答えと解説</summary>

正解: **3**

合格基準はスケールスコア 700/1000 です。単純な正答率(60%など)でも、相対評価(上位何%)でもありません。CAT では問題の難易度を加味して実力を推定するため、「何問正解したか」がそのまま合否になるわけではない点を理解しておきましょう。

</details>

**問3.** CAT 方式の CISSP 試験で「できない」ことはどれでしょう？

1. 日本語で受験すること
2. 前の問題に戻って答えを修正すること
3. 試験時間を全部使い切ること
4. 難しい問題に出会うこと

<details><summary>答えと解説</summary>

正解: **2**

CAT では回答を確定すると次の問題に進み、前の問題には戻れません（見直し不可）。これは「受験者の回答に応じて次の問題を選ぶ」という CAT の仕組み上の制約です。日本語受験は可能で、時間を使い切ることも、実力者ほど難問が続くこともあります。見直し前提の解き方が通用しない点が最大の注意点です。

</details>

**問4.** 8ドメインのうち、出題比率が最も高いのはどれでしょう？

1. D4 通信とネットワークのセキュリティ
2. D8 ソフトウェア開発セキュリティ
3. D7 セキュリティの運用
4. D1 セキュリティとリスクマネジメント

<details><summary>答えと解説</summary>

正解: **4**

D1 セキュリティとリスクマネジメントが 16% で最大です。CISSP が「マネジメントの試験」といわれる理由がこの比率にも表れています。D4 と D7 は各13%、D8 は10%です。最小は D2 と D8 の10%、という対比もあわせて覚えておくと確実です。

</details>

**問5.** CAT 方式の試験中、残り時間に対して明らかに判断に迷う問題に出会ったとき、最も適切な(BEST)行動はどれでしょう？

1. 時間をかけてでも完全に納得できるまで考え抜く
2. その問題をスキップして次に進み、最後に戻って解く
3. 消去法で最も妥当な選択肢を選び、確定して前進する
4. 残りの問題をすべてランダムに回答して早く終わらせる

<details><summary>答えと解説</summary>

正解: **3**

CAT では前に戻れないため「後で解く」は不可能で、スキップ機能もありません。1問に時間をかけすぎると後半の問題に回答できなくなるので、消去法で最善の選択肢を選んで前進するのが BEST です。ランダム回答は実力推定を大きく下げます。この「BEST を1つ選ぶ」という問い方自体が CISSP の典型スタイルなので、問題文の感覚にも慣れておきましょう。

</details>

## 3. マネジメント視点の解法 — Think like a Manager

### CISSP 最大の特徴

CISSP の問題は「技術的に正しい選択肢」が複数並びます。そこから**組織の管理者 (manager) として最も適切 (BEST) なもの**を選ぶのが CISSP 流です。これを **Think like a Manager** と呼びます。

### 鉄則の優先順位

1. **人命・安全 (human life / safety) が常に最優先**。迷ったら人を守る選択肢
2. 次に**事業継続**（組織が生き残ること）
3. その次に**資産・データの保護**

### CISSP 的思考の癖

- 対策を選ぶ前に、**まずリスク評価 (risk assessment)**（どんな脅威がどれくらい起こりそうで、起きたら損害がどれほどかを見積もり、対策の優先順位を決めること。L4 で詳しく扱います）。「いきなり製品導入」は大抵誤り
- 何をするにも**ポリシー**（経営層が承認した組織の方針文書。L2 で詳しく扱います）**と経営層 (senior management) の支持が先**。現場の独断で進める選択肢は怪しい
- 技術で解決する前に**プロセスや管理体制を疑う**
- 恒久対策の前に、まず影響の**封じ込め**（被害が広がらないよう、感染した PC をネットワークから切り離すなどの初動）など**手順 (process) に沿った行動**を取る

### 修飾語を見逃さない

| 修飾語 | 意味 |
|---|---|
| BEST / MOST | 全部正しそうでも「最も」適切な1つを選ぶ |
| FIRST | 「最初に」行うべき一手（例: まず評価、まず封じ込め） |
| LEAST / NOT | 「最も不適切」「当てはまらないもの」を選ぶ逆質問 |

### 例題で解き方をたどる

「社員の PC がランサムウェア（ファイルを勝手に暗号化して身代金を要求する不正プログラム）に感染したと報告がありました。**最初に (FIRST)** 行うべきことはどれか」という問題で、次の4つが並んだとします。

| 選択肢 | 正しい行動か | いつやるか |
|---|---|---|
| 感染した PC をネットワークから切り離す | 正しい | **すぐ**（被害の拡大を止める封じ込め） |
| 全社に新しいウイルス対策製品を導入する | 正しい | 後で（再発防止の恒久対策） |
| バックアップから PC を復元する | 正しい | 封じ込めの後（先に戻すと再感染し得る） |
| 警察に通報する | 場合による | 経営層・法務と相談して判断 |

4つとも「やってよいこと」ですが、修飾語は FIRST なので、手順の最初に来る**切り離し（封じ込め）**が正解です。このように「どれが正しいか」ではなく「この修飾語の下でどれが一番か」で選びます（インシデント対応の手順は L25 で詳しく扱います）。

### 日本語受験の注意

日本語訳が不自然なことがあります。違和感を覚えたら、**英語の原語（due diligence、tailoring など）を推測して読み替える**と意図がつかめます。たとえば due diligence は「事前の調査・確認」、tailoring は「標準の対策セットを自社の事情に合わせて取捨選択すること」で、直訳調の訳語だと意味が取りにくい代表例です。本講座で用語に英語を併記しているのはこのためです。

### 確認問題

**問1.** CISSP 的な考え方で、どんな状況でも常に最優先すべきものはどれでしょう？

1. 人命と安全
2. 顧客データの機密性
3. システムの可用性
4. 会社の利益

<details><summary>答えと解説</summary>

正解: **1**

CISSP では人命・安全 (human life / safety) が常に最優先です。データ保護や可用性、利益よりも上位に置かれます。たとえば火災時の物理セキュリティの問題では「データセンターの施錠維持」より「人の避難」が正解になります。『セキュリティの試験だからデータ保護が最優先』と考えてしまうのが典型的な誤りです。

</details>

**問2.** セキュリティプログラムを新設する際、最初に行うべき (FIRST) ものはどれでしょう？

1. 最新のファイアウォールとEDRを導入する
2. 全従業員にセキュリティ研修を実施する
3. 経営層の支持を得てセキュリティポリシーを策定する
4. ペネトレーションテストを外部委託する

<details><summary>答えと解説</summary>

正解: **3**

セキュリティプログラムの土台は経営層 (senior management) の支持とポリシーです。これがないと予算も権限も続きません。製品導入・研修・テストはすべて「正しいが、ポリシーと経営支持の後」に来るものです。CISSP では『技術的な対策から入る選択肢』は FIRST 問題ではほぼ誤り、と覚えておきましょう。

</details>

**問3.** 「新しい脅威への対策として最も適切 (BEST) なものはどれか」という問題で、選択肢が4つとも技術的に正しく見える場合、CISSP 流の選び方はどれでしょう？

1. 最も高価で高機能な対策を選ぶ
2. 最も新しい技術を使った対策を選ぶ
3. 最も詳しく技術が説明されている選択肢を選ぶ
4. リスク評価に基づき、組織全体の視点で最も妥当な対策を選ぶ

<details><summary>答えと解説</summary>

正解: **4**

CISSP の BEST 問題は「全部正しそう」が前提です。その中から、リスク評価に基づく判断・組織全体(マネジメント)の視点という軸で最も妥当なものを選びます。高価・最新・説明が詳しいといった表面的な特徴は判断基準になりません。むしろ具体的な製品名や細かい技術が書かれた選択肢は、視点が低い(現場寄りすぎる)ことが多い点に注意しましょう。

</details>

**問4.** 問題文に LEAST や NOT が含まれる場合の正しい読み方はどれでしょう？

1. 通常どおり最も適切な選択肢を選ぶ
2. 「最も当てはまらない・最も不適切なもの」を選ぶ逆質問として読む
3. LEAST は無視してよい修飾語である
4. すべての選択肢が誤りなので回答をスキップする

<details><summary>答えと解説</summary>

正解: **2**

LEAST / NOT は「最も不適切なもの」「当てはまらないもの」を選ばせる逆質問の合図です。読み飛ばすと、正しい知識があるのに真逆の選択肢を選んでしまいます。CAT は見直しできないため、この読み違いは致命的です。修飾語 (BEST/MOST/FIRST/LEAST/NOT) に下線を引くつもりで問題文を読む癖をつけましょう。なおスキップという操作は CAT には存在しません。

</details>

**問5.** 日本語で受験中、問題文の訳語が不自然で意味がつかめないとき、最も適切な (BEST) 対処はどれでしょう？

1. その問題は適当に選んで忘れる
2. 試験官に正しい日本語訳を質問する
3. 元の英語の専門用語を推測し、学習した原語の知識で読み替える
4. 不自然な訳語の問題は採点されないので気にしない

<details><summary>答えと解説</summary>

正解: **3**

日本語版は翻訳の癖があるため、学習時から英語の原語 (due diligence, tailoring など) をセットで覚えておき、不自然な訳語に出会ったら原語を推測して読み替えるのが BEST です。試験官は問題内容に答えられませんし、訳が不自然でも採点対象です。適当に選ぶのは、推測で読み替える努力をした上での最終手段です。

</details>
