# 第13章 物理セキュリティと環境対策【D3】

D3の締めくくりは物理セキュリティです。CISSPでは「どんなに論理的な防御が強くても、物理的に侵入されたら終わり」という視点と、「物理セキュリティでも人命が常に最優先」という鉄則が繰り返し問われます。サイト設計・電源・火災対策という3つの定番テーマを、対比表で確実に覚えましょう。

## 1. サイト設計と入退管理

### 物理セキュリティは「設計」から始まる

物理セキュリティは、建物・部屋・機器そのものを、侵入・盗難・災害から守る分野です。どんなに強い暗号やパスワードを使っていても、サーバー本体を持ち出されたりディスクを抜かれたりすれば守れません。そのため「人が物理的に近づけるか」を最初に固めます。

**CPTED（環境設計による犯罪予防, Crime Prevention Through Environmental Design）** は、建物や敷地の設計そのもので犯罪を起こしにくくする考え方です。3つの柱で覚えましょう。

| CPTEDの柱 | 内容 | 例 |
|---|---|---|
| 自然な監視 (natural surveillance) | 人の目が届く設計 | 見通しのよい配置、十分な照明、低い植え込み |
| 自然なアクセス制御 (natural access control) | 動線を絞る設計 | 入口を1か所に、ゲートや通路で誘導 |
| 領域性の強化 (territorial reinforcement) | 「管理された場所」と示す | 看板、舗装の切り替え、手入れされた外構 |

立地選定では、洪水・地震などの**自然災害**、周辺施設（空港・化学工場・デモの多い場所）、緊急サービスへの近さを評価します。既に建ててから動かすことはできないため、**立地のリスク評価は最初に行う**のが鉄則です。

### 多層の物理防御

侵入者は「敷地の外周 → 建物の入口 → フロア → サーバー室 → ラック」の順に近づきます。1つの対策が破られても次の層で止まるように、外側から内側へ何重にも対策を重ねます（多層防御, defense in depth）。

| 対策 | ポイント |
|---|---|
| フェンス | 高さ約1m（3〜4フィート）=うっかり立ち入る人を防ぐ程度、約2m（6〜7フィート）=よじ登りにくい、約2.4m（8フィート）+有刺鉄線=本気の侵入者も抑止 |
| 照明 | 最も基本的な抑止策。死角をなくす |
| ボラード (bollard) | 建物の前に立てる鉄やコンクリートの低い柱。車両の突入を物理的に阻止 |
| 警備員 | **状況に応じて判断・対応できる唯一の対策**。ただしコスト高・人的リスクあり |
| 警備犬 | 抑止力は高いが、けがをさせる法的責任に注意 |

### 入退管理

**マントラップ（アクセス制御前室, mantrap / access control vestibule）** は2枚の扉で挟まれた小部屋で、1人ずつしか通さない仕組みです。認証した人のすぐ後ろについて一緒に入り込む **ピギーバック（piggybacking）／テールゲーティング（tailgating）** への最も効果的な対策で、超頻出です（回転式ゲート turnstile も同じ目的）。ピギーバックは正規の利用者が承知のうえで（親切心などで）一緒に通す場合、テールゲーティングは利用者が気づかないうちに後ろについて入る場合を指すことが多いですが、試験ではほぼ同じ「共連れ」として扱われます。

入退記録の1行は、たとえば次のような形です。

```
2026-11-13 08:59:41 DOOR=DC-1F-IN  BADGE=10234  NAME=yamada  RESULT=GRANTED  PERSONS=2
```

- `DOOR=DC-1F-IN`: どの扉か（データセンター1階の入口）
- `BADGE=10234` / `NAME=yamada`: かざされたバッジと持ち主
- `RESULT=GRANTED`: 認証は成功
- `PERSONS=2`: 扉のセンサーが数えた通過人数。認証は1回なのに2人通っている＝共連れの疑い

このように普通の扉では「起きた後に記録で気づく」ことしかできません。マントラップは1人分の認証が済まないと内側の扉が開かないので、起きる前に止められます。訪問者には受付での記帳・バッジ・**エスコート（付き添い）** を義務付けます。

監視カメラ（CCTV, 閉回路テレビ＝決まった受像機にだけ映像を送るカメラ網）は**抑止（deterrent）と記録・発見（detective）** を兼ねます。L2で見た統制の種類でいうと、「見られている」と思わせて思いとどまらせるのが抑止、録画を見て後から侵入に気づくのが発見で、扉のように侵入そのものを止める予防（preventive）ではありません。

侵入検知センサーは「何の変化を検知するか」で方式が分かれます。

| 方式 | 検知するもの | 使われる場面 |
|---|---|---|
| 赤外線（パッシブ赤外線） | 人の体温による熱の変化 | 部屋の中の人の動き |
| 超音波 | 発した音波の反射パターンの変化 | 部屋の中の動き |
| 静電容量 | 周囲に作った電界の変化（近づくと変わる） | 金庫・重要な機器のすぐそば |
| 光電（フォトエレクトリック） | 発した光線が遮られたこと | 通路・扉を横切る動き |

💡 コツ: 「共連れを防ぐ最良の対策は？」と来たらマントラップ。「柔軟な判断ができる対策は？」と来たら警備員。問われ方のパターンで覚えましょう。

### 確認問題

**問1.** データセンターの入口で、社員証をかざした従業員のすぐ後ろに続いて、認証せずに入館する「共連れ（テールゲーティング）」が問題になっています。これを防ぐ対策として最も効果的（BEST）なものはどれでしょう？

1. 監視カメラを入口に増設する
2. 全従業員にセキュリティ意識向上の研修を行う
3. マントラップ（アクセス制御前室）を設置する
4. 入口の照明を明るくする

<details><summary>答えと解説</summary>

正解: **3**

マントラップは2枚の扉の間の小部屋で物理的に1人ずつしか通さないため、共連れを構造的に不可能にします。監視カメラは記録と抑止はできますが侵入自体は止められません（発見的対策）。研修は有効ですが人の善意頼みで確実性に欠けます。照明は夜間の抑止にすぎません。試験では「最も効果的」と聞かれたら、人の注意に頼る対策より物理的・構造的に防ぐ対策を選ぶのがコツです。

</details>

**問2.** CPTED（環境設計による犯罪予防）の「自然な監視 (natural surveillance)」に該当する取り組みはどれでしょう？

1. 植え込みを低くし、駐車場全体を見通せるように照明を配置する
2. 敷地の入口に「関係者以外立入禁止」の看板を設置する
3. 来訪者の動線が必ず受付の前を通るように通路を設計する
4. 建物の周囲に高さ2mのフェンスと有刺鉄線を設置する

<details><summary>答えと解説</summary>

正解: **1**

自然な監視とは「人の目が自然に届く」設計のことで、見通しの確保と照明が代表例です。看板は領域性の強化、受付前を通る動線は自然なアクセス制御にあたります。フェンスはCPTEDの3本柱ではなく従来型の物理障壁です。試験ではCPTEDの3つの柱（監視・アクセス制御・領域性）のどれに当たるかを仕分けさせる問題が出ます。

</details>

**問3.** 新しいデータセンターの建設地を選定するプロジェクトが始まりました。セキュリティ専門家として最初に（FIRST）行うべきことはどれでしょう？

1. 入退管理システムのベンダーを選定する
2. 候補地の自然災害や周辺環境のリスクを評価する
3. フェンスと監視カメラの設置計画を作成する
4. 警備会社と契約条件を交渉する

<details><summary>答えと解説</summary>

正解: **2**

立地は後から変更できない最上流の決定なので、候補地の洪水・地震・周辺施設などのリスク評価が最初です。入退管理・フェンス・警備はいずれも立地が決まった後の設計・運用段階の話です。CISSPでは「FIRSTはリスク評価」「技術や製品の選定は後」というパターンが物理セキュリティでも一貫して通用します。

</details>

**問4.** 物理セキュリティ対策のうち、状況に応じた柔軟な判断と対応ができる点で他の対策より優れているものはどれでしょう？

1. ボラード
2. 静電容量センサー
3. 監視カメラ（CCTV）
4. 警備員

<details><summary>答えと解説</summary>

正解: **4**

警備員は人間なので、不審な行動の見極め、来訪者への対応、緊急時の避難誘導など状況判断を伴う対応ができる唯一の対策です。その代わりコストが高く、ソーシャルエンジニアリングに騙されるなど人的な弱点もあります。ボラードは車両阻止専用、センサーとカメラは検知・記録のみで自ら対応はできません。「柔軟性・判断力＝警備員」は定番の出題パターンです。

</details>

**問5.** 侵入検知センサーのうち、監視対象の周囲に発生させた電界（電磁場）の変化によって人の接近を検知する方式はどれでしょう？

1. 赤外線センサー
2. 超音波センサー
3. 静電容量センサー
4. 光電（フォトエレクトリック）センサー

<details><summary>答えと解説</summary>

正解: **3**

静電容量センサー (capacitance sensor) は物体の周囲の電界の変化を検知する近接検知方式で、金庫や重要物の至近距離の防護に使われます。赤外線センサーは熱（温度変化）、超音波センサーは音波の反射パターンの変化、光電センサーは光線の遮断を検知します。試験では「何の変化を検知するか」でセンサー方式を対応付けさせる問題が出るため、熱=赤外線・音=超音波・電界=静電容量と整理しましょう。

</details>

## 2. 電源と環境制御

### 電源異常の用語を正確に

コンセントの電気は、決まった電圧（日本の一般的なコンセントは100V）で途切れずに届く前提で機器が設計されています。電圧が下がりすぎるとサーバーが突然止まり、上がりすぎると部品が壊れます。止まり方によってはディスクへの書き込み途中のデータが壊れるため、可用性と完全性の両方の問題です。

電源トラブルの用語は対比表で問われる定番です。**瞬間か継続か × 高いか低いか** で整理しましょう。

| 用語 | 意味 |
|---|---|
| フォールト (fault) | 瞬間的な停電 |
| ブラックアウト (blackout) | 長時間の完全停電 |
| サグ (sag) / ディップ | 瞬間的な電圧低下 |
| ブラウンアウト (brownout) | 長時間の電圧低下 |
| スパイク (spike) | 瞬間的な過電圧 |
| サージ (surge) | 継続的な過電圧 |
| インラッシュ (inrush) | 機器接続直後に流れる突入電流 |

覚え方は2軸の表です（インラッシュは別枠）。

| | 瞬間的 | 長時間 |
|---|---|---|
| 電気が来ない（0V） | フォールト | ブラックアウト |
| 電圧が低い | サグ | ブラウンアウト |
| 電圧が高い | スパイク | サージ |

過電圧（スパイク・サージ）から機器を守るのが**サージプロテクタ**（過電圧を逃がして機器に届かないようにする装置）で、停電には効きません。

### UPSと発電機は役割分担

- **UPS（無停電電源装置）**: バッテリーで**瞬断や短時間の停電**をしのぎ、ノイズを除いたクリーンな電力を供給します。もつのは数分〜数十分です
- **発電機 (generator)**: 起動に時間がかかる代わりに、燃料がある限り**長時間**給電できます

停電が起きたときの流れを時刻で追うと、役割分担がはっきりします。

| 時刻 | 起きること | 給電しているもの |
|---|---|---|
| 10:00:00 | 停電発生 | UPS（バッテリーに瞬時に切り替わるので、サーバーは止まらない） |
| 10:00:10 頃 | 発電機が自動起動し、電圧が安定する | UPS |
| 10:00:30 頃 | 給電元が発電機に切り替わる | 発電機（UPS はバッテリーを充電し直す） |
| 〜燃料が続く限り | 長時間の給電 | 発電機（燃料の備蓄と補給契約が必要） |

UPS のバッテリーは数分〜数十分しかもたないので、発電機が起動しなかった場合に備え、その間にサーバーを安全にシャットダウンする手順も決めておきます。

💡 コツ: 「停電時、発電機が起動するまでの橋渡し」がUPSの役割です。「長時間の停電対策にBESTは？」と聞かれてUPSを選ばせるひっかけが定番です。

### HVACと温湿度

データセンターの環境は **HVAC（空調, Heating, Ventilation and Air Conditioning）** で管理します。

| 項目 | ポイント |
|---|---|
| 温度 | 推奨帯域はおおむね15〜27℃程度（ASHRAE＝米国の空調学会のガイドライン） |
| 湿度 | 相対湿度はおおむね40〜60%程度に保つのが目安 |
| 湿度が低すぎる | **静電気 (static electricity)** による機器破損（静電気がたまって一気に流れる静電気放電＝ESD が電子部品を壊す） |
| 湿度が高すぎる | **結露・腐食 (corrosion)** |
| ホットアイル/コールドアイル | ラックの向きを揃えて排熱と吸気を分離し、冷却効率を上げる配置 |
| 正圧換気 (positive pressure) | 室内の気圧を外より高くし、ほこりや汚染空気の流入を防ぐ |

水害対策としてサーバー室は**地下や最上階を避けた上層階**に置き、床下に**水検知センサー**を設けます。配管の真下にサーバーを置かないことも重要です。また、モーターや蛍光灯などが発する **EMI/RFI（電磁干渉/無線周波干渉）** はケーブルのシールドや距離の確保で防ぎます。

物理環境でも判断基準は変わりません。環境制御の失敗（火災・感電・空調停止時の熱）で危険が生じる場面では、**設備より先に人の安全**を確保します。

### 確認問題

**問1.** 電源異常のうち、「長時間にわたる電圧の低下」を指す用語はどれでしょう？

1. サグ (sag)
2. ブラウンアウト (brownout)
3. フォールト (fault)
4. サージ (surge)

<details><summary>答えと解説</summary>

正解: **2**

ブラウンアウトは長時間の電圧低下です。サグは同じ電圧低下でも瞬間的なもの、という対比が最大のひっかけポイントです。フォールトは瞬間的な停電（電圧ゼロ）、サージは逆に継続的な過電圧を指します。「瞬間か長時間か」「低下か過電圧か」の2軸で7用語を表にして覚えると確実です。

</details>

**問2.** データセンターの電源設計で、UPS（無停電電源装置）が果たす役割として最も適切（BEST）な説明はどれでしょう？

1. 数日間の停電でもデータセンターを稼働させ続ける
2. 落雷による過電圧を建物の外で遮断する
3. 停電発生から発電機が起動するまでの間、瞬断なく電力を供給する
4. 機器の突入電流（インラッシュ）を増幅して起動を早める

<details><summary>答えと解説</summary>

正解: **3**

UPSはバッテリーによる短時間の給電装置で、停電の瞬間を途切れなくしのぎ、長時間用の発電機が起動するまでの橋渡しをするのが本来の役割です。数日間の停電に耐えるのは発電機（燃料補給前提）の仕事で、UPSのバッテリーでは持ちません。落雷対策は避雷設備やサージプロテクタの役割です。「機器の突入電流（インラッシュ）を増幅して起動を早める」は意味が逆で、突入電流は抑えるべきものです。

</details>

**問3.** サーバー室の湿度が推奨値より大幅に低い状態が続いています。この状況で最も懸念すべきリスクはどれでしょう？

1. 静電気の放電による電子部品の破損
2. 結露による機器内部の腐食
3. カビの発生による空調フィルターの詰まり
4. 気圧低下によるハードディスクの故障

<details><summary>答えと解説</summary>

正解: **1**

湿度が低い＝乾燥すると静電気が発生しやすくなり、静電気放電 (ESD) が電子部品を破壊します。結露や腐食、カビは逆に湿度が高すぎる場合のリスクです。「低い→静電気、高い→腐食」のペアは頻出で、どちらのリスクか入れ替えて出題されるので注意しましょう。気圧とハードディスクの組み合わせは湿度とは関係のないダミーです。

</details>

**問4.** データセンターでラックの向きを揃え、サーバーの吸気面どうし・排気面どうしを向かい合わせに配置する「ホットアイル/コールドアイル」方式の主な目的はどれでしょう？

1. ラック間の通路を広げて避難経路を確保する
2. 暖気と冷気の混合を防ぎ、冷却効率を高める
3. 電磁干渉（EMI）を列ごとに遮蔽する
4. 火災時に延焼を一方向に限定する

<details><summary>答えと解説</summary>

正解: **2**

ホットアイル/コールドアイルは、冷たい吸気と熱い排気の通路を分離することで暖気と冷気が混ざるのを防ぎ、空調（HVAC）の冷却効率を上げる配置手法です。避難経路や延焼防止、EMI対策は別の設計要素で、この配置の目的ではありません。環境制御の問題では「何のための配置・設備か」という目的を問う形が多いので、目的とセットで覚えましょう。

</details>

**問5.** 停電が頻発し、復旧まで数時間かかることもある地域にデータセンターを構えます。長時間の停電対策として最も適切（BEST）な構成はどれでしょう？

1. 大容量のUPSを複数台直列に接続する
2. サージプロテクタを全ラックに設置する
3. 全サーバーを省電力モードで常時運用する
4. UPSで瞬断をしのぎ、燃料備蓄のある発電機に切り替える

<details><summary>答えと解説</summary>

正解: **4**

数時間規模の停電にはUPS＋発電機の組み合わせが正解です。UPSが停電の瞬間を支え、起動した発電機が長時間の給電を引き受けます。UPSを何台並べてもバッテリーである以上、数時間の全館給電は現実的ではありません（これが定番のひっかけです）。サージプロテクタは過電圧対策であり停電対策ではなく、省電力モードは消費を減らすだけで給電源にはなりません。

</details>

## 3. 火災対策

### 火災が起きたら、何よりも先に人の避難

CISSPの鉄則どおり、火災対応の最優先は**人命・安全 (life safety)** です。「消火」「データ保護」「原因調査」のどれよりも先に、まず**人員の避難**。これは物理セキュリティ分野で最も確実に出る考え方です。

### 火の三要素と消火の原理

火は**燃料・熱・酸素**（＋連鎖反応＝燃焼でできた物質が次の燃焼を引き起こし続ける化学反応）で燃え続けます。消火とはこのどれかを断つことです。水は熱を奪い、ガス系消火剤は酸素を断つ（または連鎖反応を止める）、という対応関係で整理しましょう。

### 火災クラスと消火剤（超頻出）

| クラス | 燃えるもの | 適した消火剤 |
|---|---|---|
| A | 紙・木などの普通可燃物 | 水、泡 |
| B | 油・ガソリンなどの液体 | 泡、CO2、粉末（水は火を広げるのでNG） |
| C | 電気火災（通電中の機器） | CO2、クリーンエージェント（水は感電・機器破損のリスク） |
| D | マグネシウムなどの金属 | 専用の乾燥粉末 |
| K | 厨房の食用油・油脂 | 湿式化学消火剤（社員食堂などで出題されることがある） |

クラス分けは米国の基準（NFPA）に基づくもので、日本の消火器の表示（普通火災・油火災・電気火災）とは記号の付け方が異なります。CISSP では上の表のとおりに覚えます。

💡 コツ: データセンターの火災は基本 **クラスC**。「水以外」を選ぶのが原則です。

### 検知器とスプリンクラー方式（超頻出）

検知器には次の種類があります。

| 検知器 | 何で検知するか | 特徴 |
|---|---|---|
| 熱感知 | 温度が一定値を超える、または急に上がる | 誤報が少ないが、火が大きくなってから反応する（遅い） |
| 煙感知（イオン化式） | 煙の粒子で内部の微弱な電流が変わる | 炎の上がる火災の小さな粒子に強い |
| 煙感知（光電式） | 煙の粒子で内部の光が散乱する | くすぶる火災の大きな粒子に強い |
| 炎感知 | 炎が出す赤外線・紫外線 | 反応が最も速いが高価 |

スプリンクラーの**ヘッド**とは、天井の配管の先に付いた放水口のことです。ヘッドの中のガラス球や金属片が熱（たとえば約70℃）で割れたり溶けたりすると栓が外れ、そのヘッドから水が出ます。

| スプリンクラー方式 | 仕組み | 向き不向き |
|---|---|---|
| 湿式 (wet pipe) | 配管に常に水。ヘッド開放で即放水 | 安価で確実だが、誤作動・凍結で水損 |
| 乾式 (dry pipe) | 配管は圧縮空気。作動後に水が流れる | 凍結する環境向け |
| プリアクション (preaction) | 火災検知＋ヘッド開放の**2段階**がそろって初めて放水 | **データセンター向き**。誤作動の水損を防げる |
| 一斉開放 (deluge) | 全ヘッドから一斉大量放水 | 化学プラントなど。IT機器には不向き |

プリアクションが誤作動に強い理由を、動きの順で見てみます。

1. 平常時: 配管の中は空（空気）。ヘッドの1つが誤って壊れても水は出ない
2. 煙感知器が火災を検知 → 制御弁が開き、配管に水が満ちる（まだ放水しない）
3. 火の真上のヘッドが熱で開く → そのヘッドからだけ放水

「感知器の誤報」だけ、または「ヘッドの破損」だけでは水が出ず、両方がそろったときだけ放水されるので、誤作動による水損（水による機器の被害）が起きにくくなります。

### ガス消火

水を使えない部屋では**クリーンエージェント**（FM-200などのハロン代替ガス。放出後に残留物が残らず、機器を汚さない消火剤）や**CO2**（二酸化炭素）を使います。CO2は酸素を奪って消火するため、**在室者の窒息という人命リスク**があり、放出前の退避警報が必須です。かつて主流だった**ハロン (halon)** は**オゾン層破壊**のためモントリオール議定書で新規製造が禁止され、代替ガスへ移行しました。

### 確認問題

**問1.** 稼働中のサーバーから出火した電気火災（クラスC）に使用する消火剤として最も適切なものはどれでしょう？

1. 水を使ったスプリンクラー
2. クラスA用の強化液（水系）消火器
3. クリーンエージェント（FM-200などのガス系消火剤）
4. 金属火災用の乾燥粉末

<details><summary>答えと解説</summary>

正解: **3**

通電中の機器の火災（クラスC）に水系を使うと感電や機器破損のリスクがあるため、酸素遮断や連鎖反応の抑制で消すガス系（CO2やクリーンエージェント）が適切です。水を使ったスプリンクラーも強化液消火器もいずれも水系でクラスCにはNG。乾燥粉末はマグネシウムなどのクラスD（金属火災）専用です。「火災クラスと消火剤の対応」は表の丸暗記がそのまま得点になる超頻出ポイントです。

</details>

**問2.** データセンターのスプリンクラーとして、「火災検知システムの作動」と「スプリンクラーヘッドの開放」の両方の条件がそろって初めて放水される方式はどれでしょう？

1. 湿式 (wet pipe)
2. プリアクション (preaction)
3. 乾式 (dry pipe)
4. 一斉開放 (deluge)

<details><summary>答えと解説</summary>

正解: **2**

プリアクション方式は検知とヘッド開放の2段階がそろうまで水が出ないため、誤作動による水損リスクを最小化でき、IT機器の多いデータセンターに最適とされます。湿式は配管に常に水があり誤作動で即水損、乾式は凍結対策が主目的で2段階条件はありません。一斉開放（deluge）は全ヘッドから大量放水する方式で、精密機器の部屋には最も不向きです。

</details>

**問3.** CO2（二酸化炭素）消火設備を導入する際に、最も重大な懸念として考慮すべきものはどれでしょう？

1. 放出時に室内の人が窒息する危険がある
2. 消火後に機器に腐食性の残留物が残る
3. オゾン層を破壊するため国際条約で規制されている
4. 水損によりサーバーが故障する

<details><summary>答えと解説</summary>

正解: **1**

CO2は室内の酸素を奪って消火するため、在室者の窒息という人命リスクが最大の懸念です。放出前の警報と退避時間の確保が必須です。CO2はガスなので残留物や水損はなく（これらは粉末や水系の話）、オゾン層破壊で規制されたのはハロンです。CISSPでは「人命に関わる選択肢が最重要」という視点からも正解を導けます。

</details>

**問4.** 勤務時間中のオフィスフロアで火災報知器が作動し、煙が確認されました。セキュリティ管理者として最初に（FIRST)行うべきことはどれでしょう？

1. 消火器で初期消火を試みる
2. サーバーの緊急シャットダウンを実行する
3. 全員をあらかじめ定めた避難経路から退避させる
4. 出火元を特定して消防に正確な情報を伝える

<details><summary>答えと解説</summary>

正解: **3**

CISSPの大原則どおり、人命・安全が常に最優先なので、まず人の避難です。初期消火・サーバー保護・原因特定はすべて人の安全が確保された後の行動です。試験では「もっともらしいIT的対応（シャットダウンなど）」を混ぜて人命より先に選ばせようとするひっかけが定番ですが、人命＞事業＞資産の優先順位は絶対に揺らぎません。

</details>

**問5.** 消火剤としてのハロン (halon) が新規製造されなくなり、FM-200などの代替ガスに置き換えられた理由はどれでしょう？

1. 消火能力が低く、再発火を防げなかったため
2. 放出時に機器を腐食させる残留物が多かったため
3. 製造コストが代替ガスの数十倍だったため
4. オゾン層破壊物質として国際的に規制されたため

<details><summary>答えと解説</summary>

正解: **4**

ハロンは優れた消火能力を持ちますが、オゾン層破壊物質としてモントリオール議定書で新規製造が禁止され、FM-200などのクリーンエージェントに置き換えられました。消火能力の低さや残留物が理由ではありません（むしろ残留物が少ないのがハロン系の長所です）。「ハロン＝オゾン層＝モントリオール議定書」のセットで覚えれば一瞬で解ける知識問題です。

</details>
